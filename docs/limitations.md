# 已知限制

这份清单列出**有意接受**的取舍和**尚未验证**的部分。它们不是待办列表，而是交付边界：读的人应该能判断哪些场景可以直接用，哪些需要先补工作。

## 1. 资金与支付

- **支付通道是模拟实现。** 充值、打款、回调、查询均为本地可控链路，不接真实渠道。签名字段、幂等键、状态机、重试与人工复核是真的，但外部通道的行为是模拟的。
- **没有真实退款时效验证。** 退款走本地记账，不涉及银行或第三方支付的到账时间。
- **没有多币种。** 金额统一人民币分，汇率、币种、跨境结算不在范围内。
- **没有资金存管资质相关实现。** 平台账户与托管账户是账务模型，不对应真实存管银行账户。

## 2. 部署与规模

- **按单实例交付。** 会话在 Redis，业务无状态，理论上可水平扩展；但本地缓存、定时任务、预算预检没有做多实例协调。ShedLock 只保证定时任务不重复执行，不解决缓存一致性。
- **没有压测。** 并发正确性由集成测试覆盖（条件更新、行锁、唯一索引），但没有 QPS、P99、连接池耗尽、消息积压的实测数据。
- **没有容器编排。** 提供 Docker Compose 用于本地中间件；应用本身可用 `mvn spring-boot:run` 或打包后的 jar 运行，没有 Kubernetes manifests、Helm chart、灰度发布与服务网格配置。
- **没有对象存储。** 交付物与证据文件按本地文件系统或数据库记录处理，没有接 S3/OSS，也没有分片、断点续传、病毒扫描。

## 3. 检索与 AI

- **检索是词法的。** 中文二元切分 + 同义词 + 字段加权，没有向量召回、语义近邻、跨语言检索。数据量上来后 `LIKE '%kw%'` 会成为瓶颈。
- **评测语料只有 10 人。** 八项指标只用于同语料、同 prompt 版本的回归对比，不能外推为线上效果。
- **Judge 分数依赖模型版本。** 4.72 是 `deepseek-chat` + `judge/v1` + 20 条 × 3 轮的结果，换模型或改 prompt 必须重跑，不能跨版本比较。
- **重排被拒率缺语料级统计。** 当前只有构造样例验证口径，需要 live 模式积累真实重排数据。
- **没有多模态。** 不处理图片、语音、视频输入；交付物验收以文本与文件元数据为主。
- **没有模型微调。** 全部走 Prompt + 检索 + 规则约束，没有训练或微调流程。

## 4. 测试与验证

- **97 条集成测试默认跳过。** 需要真实 MySQL/Redis，`mvn test` 不设 `ESCROW_IT` 时自动 skip。CI 的 `integration` job 会执行，但目前是 `continue-on-error`。
- **没有端到端浏览器自动化。** E2E 脚本是 HTTP 级冒烟，不覆盖真实浏览器交互、样式回归、可访问性。
- **没有故障注入。** 数据库主从切换、Redis 宕机、Kafka 积压、通道超时后的恢复路径，靠单元测试与代码审查保证，没有混沌工程验证。
- **没有安全渗透测试。** SQL 注入、XSS、CSRF、越权、会话固定有防护与契约测试，但没有第三方渗透报告。

## 5. 功能边界

- **没有真实短信与邮件。** 注册验证码、找回密码、通知外发都是本地模拟或站内信。
- **没有开放平台。** 不提供第三方应用接入、OAuth2 授权服务器、Webhook 订阅。
- **没有多租户。** 单平台运营，不支持多个组织隔离。
- **没有完整财务导出。** 对账差异可查询与处理，但没有会计科目映射、总账导出、税务报表。
- **没有客户端 App。** 只有 Vue 3 Web 控制台，移动端为响应式布局，没有原生 App 或小程序。
- **没有 OpenAPI 文档。** 接口契约由 Controller 测试与前端类型约束，未生成 Swagger/OpenAPI 页面。

## 6. 运维

- **没有备份与恢复演练。** Docker volume 持久化数据，但没有自动备份、时间点恢复、跨机房容灾。
- **没有日志聚合与告警规则。** 结构化日志与 traceId 已具备，但没有接 ELK/Loki，也没有 Prometheus 告警规则。
- **没有配置中心的生产实践。** Nacos 客户端在依赖里，本地默认不启用；配置变更、灰度、回滚没有演练。
- **没有容量规划。** 表增长、索引膨胀、归档策略只有对账报文的 Mongo 归档，没有统一的数据生命周期管理。

## 7. 兼容性

- 前端只验证 Chrome / Edge 最近两个大版本，最低分辨率 1366×768。
- 后端依赖 JDK 17；没有验证 JDK 21/25 的虚拟线程与 GC 行为。
- MySQL 8.0.42、Redis 7.4 是验证过的版本；其它小版本未做兼容性矩阵。
